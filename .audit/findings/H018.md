# H018: ZeroWager Dead Code Exploitation

**Status:** NOT VULNERABLE
**Severity:** Informational (Dead Code)
**Precedent:** EP-033

## Summary

The `ZeroWager` error code (line 817 of lib.rs) is defined but never triggered. However, the zero-wager scenario is effectively prevented by mandatory MIN_WAGER_LAMPORTS validation in `create_match`, making the error unreachable dead code rather than a security vulnerability.

## Investigation

### 1. MIN_WAGER_LAMPORTS Value
**Line 29:** `const MIN_WAGER_LAMPORTS: u64 = 10_000;`

This constant requires the minimum wager to be 10,000 lamports (~$0.000002 at $20/SOL).

### 2. Wager Validation in create_match
**Lines 120-123:**
```rust
require!(wager_lamports >= MIN_WAGER_LAMPORTS, EscrowError::WagerTooSmall);
require!(wager_lamports <= MAX_WAGER_LAMPORTS, EscrowError::WagerTooLarge);
```

Every match created must pass this validation. The error code used is `WagerTooSmall`, not `ZeroWager`.

### 3. BPS Calculation Safety
At MIN_WAGER (10,000 lamports), the pot split is:
- **Total pot:** 20,000 lamports
- **Treasury (7%):** 20,000 * 700 / 10,000 = 1,400 lamports
- **Ops (3%):** 20,000 * 300 / 10,000 = 600 lamports
- **Winner (90% + remainder):** 18,000 lamports

All amounts are positive integers; no zero-fee scenario is mathematically possible.

### 4. ZeroWager Error Status
**Line 817:** The error is defined but:
- Never emitted in any instruction
- Never checked with `require!`
- Dead code from deployment

## Root Cause

The `ZeroWager` error was likely defined during initial development but was superseded by the more general `WagerTooSmall` error code (line 836) when MIN_WAGER_LAMPORTS was introduced. The old error was not removed.

## Impact

**Security:** None. The validation gate (MIN_WAGER_LAMPORTS) is unconditional and cannot be bypassed.

**Code Quality:** Dead code should be removed in cleanup phase for clarity.

## Recommendation

Remove the unused `ZeroWager` error from the error enum (line 817) to reduce code noise and clarify that zero-wager matches are impossible by design, not by runtime check.
