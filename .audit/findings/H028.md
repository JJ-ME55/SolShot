# H028 — Zero-Padded Player Array Slice Boundary

**Hypothesis:** v1 `players: [Pubkey; 4]` and v2 `players: [Pubkey; 10]` arrays are zero-padded with `Pubkey::default()` for unused slots. A future code change that loops over the full array (instead of the safe `players[..max_players]` slice) could treat `Pubkey::default()` as a valid player, enabling an unintended account to pass validation.

## Verdict

**NOT_VULNERABLE** — All current refund and settlement loops correctly use bounded slice or explicit `max_players` guard.

## Verification

### v1 Loops (4-element array)

| Line  | Function | Loop Pattern | Guard | Status |
|-------|----------|--------------|-------|--------|
| 393–409 | `CancelMatch` handler | `ctx.remaining_accounts.iter()` + `i` index | `require!(i < max_players)` at 395 | ✓ Safe |
| 465–478 | `PermissionlessReclaim` handler | Same | `require!(i < max_players)` at 466 | ✓ Safe |
| 676–679 | `SettleMatch` constraint | `.any(\|i\| ...)` range | `(0..escrow.max_players as usize)` | ✓ Safe |

### v2 Loops (10-element array)

| Line  | Function | Loop Pattern | Guard | Status |
|-------|----------|--------------|-------|--------|
| 502–510 | `CancelMatch` handler | `ctx.remaining_accounts.iter()` + `i` index | `require!(i < max_players)` at 503 | ✓ Safe |
| 561–569 | `PermissionlessReclaim` handler | Same | `require!(i < max_players)` at 562 | ✓ Safe |
| 707–710 | `SettleMatch` constraint | `.any(\|i\| ...)` range | `(0..escrow.max_players as usize)` | ✓ Safe |

## Defense Note

The danger would surface only if:
1. A refactor changed a loop to iterate `players.iter()` or `(0..players.len())` instead of the current bounded patterns.
2. Code then relied on each element as a "valid player" without checking the deposit-mask or other constraints.
3. `Pubkey::default()` somehow appeared as a valid signer (Solana runtime does not permit this in practice).

## Recommendation

Add an invariant comment near the `players` field in both `MatchEscrow` structs (v1 line ~150, v2 line ~160):

```rust
/// INVARIANT: Always iterate as players[..max_players] or use explicit i < max_players guard.
/// Never iterate the full array—unused slots are zero-padded with Pubkey::default().
pub players: [Pubkey; 4],  // v1
pub players: [Pubkey; 10], // v2
```

## Severity

**LOW** — Currently safe; defensive note for future audits and refactors.
