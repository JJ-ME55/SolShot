# H048: Permissionless Reclaim Default-Pubkey Validation

**Status:** NOT_VULNERABLE (runtime enforced)  
**Severity:** Low (defensive gap)  
**Component:** `permissionless_reclaim` instruction  
**Location:** `programs/solshot-escrow/src/lib.rs` (lines ~570-620)

## Issue

The `permissionless_reclaim` instruction does not explicitly validate that `caller != Pubkey::default()` before using the caller as a signer and closing the PDA to them:

```rust
pub fn permissionless_reclaim(ctx: Context<PermissionlessReclaim>) -> Result<()> {
    // ... refund logic ...
    // close = caller receives rent
}

#[derive(Accounts)]
pub struct PermissionlessReclaim<'info> {
    #[account(
        mut,
        seeds = [b"match", escrow.match_id.as_bytes()],
        bump = escrow.bump,
        close = caller,  // <-- caller receives PDA lamports
    )]
    pub escrow: Account<'info, MatchEscrow>,
    
    #[account(mut)]
    pub caller: Signer<'info>,  // <-- no Pubkey::default() check
    
    // ...
}
```

The semantic intent is: "caller receives PDA rent as gas reimbursement for calling permissionless reclaim post-deadline." Combined with `close = caller`, the code leans on Solana runtime guarantees to prevent default-pubkey signers.

## Root Cause

Solana's runtime does not permit `Pubkey::default()` as a transaction signer in practice—the System Program enforces this at signature verification. However, this defense-in-depth gap omits an explicit constraint, making the safety reliant on runtime rather than program logic.

## Verification

**Solana runtime enforcement:**
- The `Signer` trait in Anchor requires the transaction to include a valid signature for that pubkey.
- `Pubkey::default()` (all-zero address) is never a valid signer in transaction verification.
- Any transaction attempting to use default-pubkey as a signer is rejected by the runtime before reaching the program.

**Result:** NOT_VULNERABLE—runtime prevents the attack surface.

## Recommendation

Add an explicit guard for defense-in-depth (optional but recommended before mainnet):

```rust
pub fn permissionless_reclaim(ctx: Context<PermissionlessReclaim>) -> Result<()> {
    let caller = ctx.accounts.caller.key();
    require!(caller != Pubkey::default(), EscrowError::InvalidCaller);
    // ... rest of logic ...
}
```

**Minimal impact:** One additional constraint check; improves code clarity and auditor confidence.
