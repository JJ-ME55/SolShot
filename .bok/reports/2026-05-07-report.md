### Methodology Highlights

1. **Local re-implementation pattern:** Per-program Cargo features mean Anchor sources cannot be `cfg(test)`-imported. Proptest tests embed a faithful reimplementation of the on-chain math (e.g., `settle_math_v2()` mirrors v2:387-454 exactly), then sweep inputs. This is the same approach used in Feb's BOK run and validated by side-by-side const_assert sanity checks.
2. **Decomposition for LiteSVM-flagged invariants:** Where the on-chain runtime context matters (e.g., snapshot atomicity, CPI count), invariants are decomposed into (a) constituent Proptest-coverable arithmetic, plus (b) source-grep / code-read verification of the runtime guards. Both halves combined provide HIGH-CONFIDENCE coverage despite no LiteSVM execution.
3. **Stacked-audit pattern:** Feb's 25 invariants for v1 are NOT re-verified — they remain valid under the unchanged v1 surface. New invariants extend coverage to v2 + the fix-bundle constants. Total = 25 (Feb, archived) + 41 (May, this run) = 66 lifetime.
