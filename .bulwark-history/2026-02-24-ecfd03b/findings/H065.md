## H065 — authenticatedWallets Memory Leak: Disconnect Handler Missing

**Verdict:** CONFIRMED

**Severity:** MEDIUM

**Evidence:**
- `server/socket-io/main.js:44-45` — `authenticatedWallets` Map keyed by socketId
- Searched entire codebase: no `delete authenticatedWallets[client.id]` in any disconnect handler
- `server/socket-io/main.js:145-151` — `broadcastRooms()` logic is debounced but doesn't clean auth map
- 30-second reconnect window (line 140) means old socketId bindings persist in memory during that window

**Recommendation:** Add `delete authenticatedWallets[client.id]` in disconnect handler AFTER reconnect window expires; or use Map.clear() with socket-level scoping.
