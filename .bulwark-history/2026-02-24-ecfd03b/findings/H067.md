## H067 — giveTurn Relay Unsanitized Payload: Confirmed by H017

**Verdict:** CONFIRMED

**Severity:** HIGH

**Evidence:**
- `server/socket-io/main.js:2479-2482` — Legacy `giveTurn` handler:
  ```
  client.on('giveTurn', (data) => {
      if (!data || typeof data !== 'object') return
      const { terrainData, pos1, pos2, rotation1, rotation2 } = data
      client.to(client.roomId).emit('recieveTurn', {terrainData, pos1, pos2, rotation1, rotation2})
  })
  ```
- No authentication check on `giveTurn` event
- Payload relayed verbatim to opponent with only type guard
- No bounds validation on pos/rotation values

**Recommendation:** Remove legacy `giveTurn` handler or add `requireAuth()` + validate all numeric fields against game bounds.
