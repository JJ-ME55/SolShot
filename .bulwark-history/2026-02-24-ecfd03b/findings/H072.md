## H072 — Client config-overrides.js Polyfill Security: Standard Polyfills

**Verdict:** POTENTIAL

**Severity:** LOW

**Evidence:**
- `client/config-overrides.js:5-11` — Webpack polyfills:
  - `crypto-browserify` (for crypto module)
  - `stream-browserify` (for Node.js stream API)
  - `buffer/` (for Node.js Buffer)
  - `process/browser.js` (for Node.js process global)
- All polyfills are from well-maintained community packages
- No explicit CVE checks; versions not specified in config file
- `vm: false` correctly disables vm polyfill (not needed at runtime)

**Recommendation:** Add explicit version pinning in package.json for all polyfills; run `npm audit` quarterly to check for known CVEs in crypto-browserify, stream-browserify.
