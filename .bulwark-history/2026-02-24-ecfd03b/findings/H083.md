## H083 — Turn Timer Clear on Room Removal

**Verdict:** POTENTIAL

**Severity:** HIGH

**Evidence:**
`server/socket-io/main.js` line 53: `var turnTimers = {}` stores per-room countdown timers. Cleanup occurs at:
- Line 427-428: `clearTimeout(turnTimers[roomId]); delete turnTimers[roomId]` (round end)
- Line 219: `delete shopTimers[roomId]` (shop cleanup)
- Line 284: `delete shopTimers[roomId]` (disconnect)

However, room removal paths (disconnect, forfeit, match end) do not consistently clear turnTimers. If a room is deleted from `rooms` map but `turnTimers[roomId]` persists, the timer callback fires on a non-existent room → accesses undefined state, triggers error handler with stale roomId reference.

**Risk:** Memory leak (timers accumulate), silent failures, potential cross-room state corruption if timer callback accidentally modifies other room's state.

**Recommendation:** Add explicit `clearTimeout(turnTimers[roomId]); delete turnTimers[roomId]` in ALL room cleanup paths: disconnect handler, forfeit, match end, room deletion.
