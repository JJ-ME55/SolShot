## H102 — Token Account Rent Exemption Griefing

**Verdict:** NOT VULNERABLE

**Severity:** INFO

**Evidence:**
Only system accounts are created on-chain in SolShot's flow:

1. **escrow.js:281-314** (`createMatchEscrow`): Creates `matchEscrow` PDA (system account), pays rent from server authority keypair. Seeds: `["match", matchId]`.
2. **escrow.js:326-372** (`buildDepositTransaction`): Client builds unsigned deposit TX. Server builds the instruction but client signs and pays fees.
3. No token accounts (ATA or otherwise) are created by server.

Rent exemption only applies to token accounts. System accounts (PDAs) are funded once per match creation. The server pays creation cost (~5000 lamports) per match, not per player.

Cost amplification is bounded by rate limits:
- `createRoom`: max 3 per 60 seconds per socket (main.js:515-523)
- Connection-level: 100 per IP per session (index.js:41-67)

**Recommendation:** No action required; rent is system account-bounded and rate-limited.
