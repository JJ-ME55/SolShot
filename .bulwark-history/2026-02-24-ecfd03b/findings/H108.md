## H108 — Terrain Seed Prediction

**Verdict:** NOT VULNERABLE

**Severity:** INFO

**Evidence:**
Terrain is generated per-round with cryptographic randomness:

1. **physics.js:62-64** (`generateTerrain`):
   - Calls `Math.random()` by default (no seed)
   - Can accept optional seed for reproducibility (testing only)

2. **Match terrain creation** (main.js:1048):
   - `const terrain = generateTerrain(TERRAIN_WIDTH, TERRAIN_HEIGHT)`
   - No seed passed — uses Math.random()

3. **Seed randomness**: JavaScript's Math.random() in Node.js:
   - Uses V8 engine's PRNG (not cryptographically secure)
   - But terrain outcome doesn't affect financial settlement
   - Only affects gameplay (weapon landing positions)

4. **Wind generation** (physics.js:62-64):
   - `export function generateWind() { return crypto.randomInt(121) - 60; }`
   - Uses `crypto.randomInt()` — CSPRNG
   - Range: [-60, +60] px/sec acceleration

**Terrain is NOT cryptographically secure**, but it doesn't matter because:
- Terrain shape doesn't determine match winner (only affects weapon damage spread)
- Server-authoritative physics validates all shots
- Attacker cannot force win by predicting terrain

Wind uses CSPRNG and correctly affects projectile trajectories server-side.

**Recommendation:** No action required; terrain is non-critical gameplay element. Wind is properly randomized.
