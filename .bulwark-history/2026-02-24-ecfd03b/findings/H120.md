## H120 — atob() Misuse for Binary Data

**Verdict:** NOT VULNERABLE

**Severity:** INFO

**Evidence:**
Grep for `atob|btoa` in server/ returns only package-lock.json (no usage). No atob() calls found in escrow.js, solana.js, or main.js. The base64 encoding for deposit transaction is handled via Anchor's serialization/deserialization, not manual atob():

- Client receives serialized TX from `buildDepositTransaction()` as base64 string (escrow.js:354-357)
- Client decodes via web3.js/wallet adapter, NOT atob()
- Server never calls atob() on crypto material

**Recommendation:** Continue avoiding atob() for crypto operations. Keep using Anchor SDK's built-in serialization.

---

**Notes:** This is correctly implemented. No vulnerability found.
