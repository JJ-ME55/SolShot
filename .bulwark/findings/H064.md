## H064 — JWT 24h Expiry Window: Configurable But Dead

**Verdict:** POTENTIAL

**Severity:** LOW

**Evidence:**
- `server/middleware/auth.js:96-101` — JWT generation with hardcoded `expiresIn: '24h'`
- `server/middleware/auth.js:110-117` — `verifyToken()` function exists but has zero call sites in codebase
- `server/socket-io/main.js` — Socket authentication uses socket flag `client.isAuthenticated`, not JWT verification
- JWT_SECRET can be configured via env var (line 19-27), but expiry is hardcoded

**Recommendation:** Remove dead JWT code or activate `verifyToken()` at all auth-required handlers; make expiry configurable via env var if JWT is kept.
