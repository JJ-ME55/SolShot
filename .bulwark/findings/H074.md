## H074 — Unhandled Promise Rejection Crashes: Global Handler Exists

**Verdict:** CONFIRMED (But Non-Fatal)

**Severity:** MEDIUM

**Evidence:**
- `server/index.js:177-183` — Global handlers installed:
  ```
  process.on('uncaughtException', (err) => {
      console.error('[FATAL] Uncaught exception:', err);
  });
  process.on('unhandledRejection', (reason) => {
      console.error('[FATAL] Unhandled rejection:', reason);
  });
  ```
- Handlers log but DO NOT exit process — allows server to continue with corrupted state
- Many async operations in socket handlers lack try/catch blocks
- Example: `server/services/solana.js` balance checks fail open without error propagation

**Recommendation:** Add `process.exit(1)` after logging fatal errors, OR wrap all async handlers in try/catch with explicit recovery logic.
