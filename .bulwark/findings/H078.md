## H078 — Dead Code in Standard.js and extraWeapons.js

**Verdict:** CONFIRMED

**Severity:** LOW

**Evidence:**
`client/src/weapons/packs/Standard/Standard.js` defines weapon classes (singleshot, etc.) with old IDs and rendering logic. This file is not imported in the new React-based UI pipeline (`CombatCard.js`, `weapons.js`).

Bash grep confirmed: `extraWeapons.js` has **zero import references** across entire codebase.

`Standard.js` contains ~10 dead weapon class definitions (e.g., `class singleshot`, `class threeshot`) unreachable from current UI.

**Impact:** Dead code increases attack surface (unused logic can be repurposed). Confuses future maintenance. No active security risk but defense-in-depth concern.

**Recommendation:** Remove `Standard.js` and `extraWeapons.js` entirely. Verify no Phaser scene initialization paths reference these files.
