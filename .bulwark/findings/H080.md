## H080 — Client @solana/spl-token Version Pinning

**Verdict:** CONFIRMED

**Severity:** LOW

**Evidence:**
`client/package.json` line 7:
```json
"@solana/spl-token": "^0.4.14",
```

Version uses caret range `^0.4.14` (allows 0.4.x updates, minor version upgrades). Not pinned to exact version (would be `0.4.14` without caret).

This library provides SPL token burn instruction building for prestige burns. Version drift can introduce subtle API changes or security fixes that silently deploy.

**Impact:** Minor vulnerability risk. Caret range is acceptable for patch updates but allows unexpected behavior changes within minor version bump (0.4.14 → 0.4.15+).

**Recommendation:** Pin to exact version: `"@solana/spl-token": "0.4.14"` for predictable deployments. Or add lock file verification in CI.
