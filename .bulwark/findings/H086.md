## H086 — Weapon Purchase Validation

**Verdict:** CONFIRMED

**Severity:** HIGH

**Evidence:**
`server/socket-io/main.js` `buyWeapon` handler (line 1489-1510):
```javascript
client.on('buyWeapon', (data) => {
    if (!requireAuth(client, 'buyWeapon')) return
    const { weaponId, roomId } = data
    const ms = matchStates[roomId]
    ...
    const weapon = getWeapon(weaponId)
    if (!weapon) {
        client.emit('buyWeaponResult', { success: false, reason: 'Unknown weapon' })
        return
    }
```

Validation checks if weapon exists in WEAPON_CATALOG. **However**, no ownership verification: does not validate if player has gold balance sufficient for purchase (done later in `spendGold()`), nor does it check if weapon is in the player's **available pool** for this match (weapon array generated by `createWeaponArray`).

Client-side weapons.js array is authoritative source but not enforced server-side. Player could buy weapon not in their array.

**Impact:** Player purchases weapon outside their allocated pool. Server-side `spendGold()` prevents exceeding balance but doesn't prevent "illegal" weapon purchases.

**Recommendation:** Cross-check weaponId against `weaponInventories[roomId][playerId]` before allowing purchase.
