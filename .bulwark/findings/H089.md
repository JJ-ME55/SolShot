## H089 — Helmet Configuration Gaps

**Verdict:** POTENTIAL

**Severity:** MEDIUM

**Evidence:**
- server/index.js:70-95 — Helmet configured with CSP and basic headers
- contentSecurityPolicy directives enabled: defaultSrc, scriptSrc, styleSrc (unsafe-inline), imgSrc, connectSrc, fontSrc, frameSrc, objectSrc, baseUri
- Missing: X-Frame-Options (frameSrc deprecated on older browsers), HSTS explicitly set
- styleSrc: ["'self'", "'unsafe-inline'"] — permits inline CSS injection (CSP-03 weak)
- crossOriginEmbedderPolicy: false — permits cross-origin embedding

**Analysis:**
Helmet is configured with CSP but has two gaps:
1. X-Frame-Options not explicitly set (relies on frameSrc: ["'none'"] which may not propagate to older clients)
2. styleSrc unsafe-inline allows CSS injection attacks to bypass script restriction; if XSS bypasses script CSP, attacker can inject styles to keylog or exfiltrate data
3. HSTS (Strict-Transport-Security) not configured — no browser-level downgrade protection for HTTPS connections

**Recommendation:** Add explicit X-Frame-Options header and remove unsafe-inline from styleSrc; set HSTS max-age ≥ 31536000.
