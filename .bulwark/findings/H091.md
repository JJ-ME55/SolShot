## H091 — MongoDB Connection String Security

**Verdict:** POTENTIAL

**Severity:** MEDIUM

**Evidence:**
- server/index.js:137-162 — MONGODB_URI read from process.env, passed to mongoose.connect() without sanitization
- server/index.js:142 — console.log('MongoDB connected') at startup (logs success state)
- No confirmation that MONGODB_URI is never logged or passed to error handlers that log it
- Architecture.md notes: MongoDB used for User model, match persistence (optional)

**Analysis:**
MONGODB_URI typically contains plaintext username:password in connection string:
```
mongodb+srv://user:password@cluster.mongodb.net/db
```
Risks:
1. If env var is logged (error handlers, debug statements), credentials exposed
2. If server crashes and logs full error with MONGODB_URI in stack trace, credentials leaked
3. Server startup log at line 142 does not include MONGODB_URI, but other errors may

**Recommendation:** Use MongoDB Atlas IP allowlisting or API keys instead of username:password; ensure .env files are .gitignore'd; use logger abstraction that never logs MONGODB_URI.
