# Milestone v1.2: Launch Readiness

**Status:** SHIPPED 2026-02-25

## Overview

SolShot v1.2 closes all code-addressable gaps from the 280-item Master Quality & Launch Checklist. Jupiter integration ships first (hackathon deadline Feb 25), followed by UI polish across all screens, stats persistence and Combat Card, onboarding and mobile polish, client security hardening, and a final checklist re-audit to confirm launch readiness. 39 requirements across 6 phases.

## Milestone Summary

**Key Decisions:**
- Jupiter Mobile wallet adapter via Reown/WalletConnect (not direct SDK)
- Jupiter Price API V3 with free API key (not deprecated lite-api)
- 0.5% platform fee on Jupiter Terminal swaps
- Self-hosted Telegram SDK (supply chain security)
- Practice mode as default landing tab (onboarding-first)
- CHK-02 security re-check skipped (deferred to post-v1.2)

**Issues Resolved:**
- ESLint webpack worker bug (DISABLE_ESLINT_PLUGIN workaround)
- html2canvas requires offscreen positioning (not display:none)
- CSP frame-src for Jupiter Plugin iframes
- String concatenation in JSX to avoid Collider.js ESLint bug

**Issues Deferred:**
- Launch gate at 47% (QA sessions + deployment not yet done)
- Telegram bot not created (requires BotFather — human task)
- Error monitoring (Sentry) — external service setup
- Mainnet deployment — separate operational process

**Technical Debt Incurred:**
- LEARN MORE href="#" placeholder (needs litepaper URL)
- FAQ content is placeholder (needs real answers)
- 7 weapon sound effects still missing
