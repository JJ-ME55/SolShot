**New account type — GlobalConfig (OC-01):**
```rust
#[account]
pub struct GlobalConfig {
    pub authority: Pubkey,   // Settlement/cancel authority
    pub treasury: Pubkey,    // 7% fee destination
    pub ops: Pubkey,         // 3% fee destination
    pub is_paused: bool,     // Emergency pause flag
    pub bump: u8,            // PDA bump
}
impl GlobalConfig {
    // 8 + 32 + 32 + 32 + 1 + 1 = 106
    pub const SPACE: usize = 8 + 32 + 32 + 32 + 1 + 1;
    pub const SEED: &'static [u8] = b"config";
}
```

**Updated MatchEscrow (OC-07):**
- Add field: `pub activated_at: i64` (between `created_at` and `bump`)
- Update SPACE: 8 + (4+32) + 32 + 32 + 32 + 8 + 1 + 1 + 1 + 8 + 8 + 1 = 168

**New instructions:**

1. `initialize_config(authority, treasury, ops)` — one-time setup, `init` on config PDA, validates authority != treasury, authority != ops, treasury != ops. Payer is signer.

2. `update_config(new_authority, new_treasury, new_ops)` — all three are `Option<Pubkey>`. Requires `has_one = authority` on config. Only updates fields where Some value provided.

3. `pause_program()` — sets `config.is_paused = true`. Requires `has_one = authority`. Must NOT check is_paused (pause must work even when already paused).

4. `unpause_program()` — sets `config.is_paused = false`. Requires `has_one = authority`. Must NOT check is_paused.

**Updated create_match (OC-04, OC-06, OC-08, OC-12):**
- Add config account to CreateMatch struct with pause guard: `constraint = !config.is_paused @ EscrowError::ProgramPaused`
- Body: Replace `require!(wager_lamports > 0, ...)` with min/max bounds check
- Body: Add `require!(player_one != ctx.accounts.authority.key(), EscrowError::AuthorityAsPlayer)` and same for player_two
- Keep existing match_id length, same-player checks

**Updated deposit_wager (OC-04, OC-07, OC-09):**

- When both deposited and state transitions to Active: set `escrow.activated_at = Clock::get()?.unix_timestamp`
- In MatchActive event: use checked arithmetic for `total_pot`: `wager.checked_mul(2).ok_or(EscrowError::ArithmeticOverflow)?`

**Updated settle_match (OC-02, OC-03, OC-04, OC-07, OC-09, OC-10, OC-11):**
- SettleMatch struct changes:
  - Add config account with pause guard and `has_one = authority`
  - Winner: add `constraint = winner.key() == escrow.player_one || winner.key() == escrow.player_two @ EscrowError::InvalidWinner`
  - Treasury: add `constraint = treasury.key() == config.treasury @ EscrowError::InvalidTreasury` and `constraint = treasury.key() != ops.key() @ EscrowError::DuplicateFeeAccount`
  - Ops: add `constraint = ops.key() == config.ops @ EscrowError::InvalidOps`
  - Keep `has_one = authority` and `close = authority` on escrow
- Body changes:
  - Remove manual `require!(winner == player_one || ...)` — now in constraint
  - Add settlement deadline check: `require!(Clock::get()?.unix_timestamp <= escrow.activated_at.checked_add(SETTLEMENT_TIMEOUT_SECONDS).ok_or(...)?, EscrowError::SettlementExpired)` — BUT only if `escrow.activated_at > 0` (handle matches created before field existed)
  - Use u128 widening for all BPS math per research Pattern 4:
    ```
    let total_pot_128 = (escrow.wager_lamports as u128).checked_mul(2).ok_or(ArithmeticOverflow)?;
    let treasury_amount = ((total_pot_128.checked_mul(TREASURY_BPS as u128).ok_or(...)?) / BPS_DENOMINATOR as u128) as u64;
    let ops_amount = ((total_pot_128.checked_mul(OPS_BPS as u128).ok_or(...)?) / BPS_DENOMINATOR as u128) as u64;
    let total_pot = total_pot_128 as u64;
    let winner_amount = total_pot.checked_sub(treasury_amount).ok_or(...)?.checked_sub(ops_amount).ok_or(...)?;
    ```
  - Read all values into locals BEFORE mutable borrow (borrow checker pattern from research Pitfall 3)
  - Set terminal state in scoped mutable borrow: `{ let escrow = &mut ctx.accounts.escrow; escrow.state = MatchState::Settled; }` (OC-10)
  - Then do lamport transfers using `ctx.accounts.escrow.to_account_info()`
  - Update MatchSettled event to include `treasury_account: ctx.accounts.treasury.key()` and `ops_account: ctx.accounts.ops.key()` (OC-11)

**Updated cancel_match (OC-04, OC-05, OC-07, OC-09, OC-10):**
- CancelMatch struct: add config account with pause guard
- Body changes:
  - Authority cancel restriction (OC-05): change logic to:
    ```
    let is_authority = caller == config.authority;
    let is_player = caller == escrow.player_one || caller == escrow.player_two;
    let is_timed_out = Clock::get()?.unix_timestamp > escrow.activated_at.checked_add(TIMEOUT_SECONDS).ok_or(...)?;
    require!(
        (is_authority && escrow.state == MatchState::AwaitingDeposits)
        || (is_player && (escrow.state == MatchState::AwaitingDeposits || is_timed_out)),
        EscrowError::Unauthorized
    );
    ```
    Note: authority can ONLY cancel AwaitingDeposits. Players can cancel AwaitingDeposits or timed-out Active.
  - Use `activated_at` not `created_at` for timeout (OC-07). Handle case where activated_at is 0 (match never became Active): if `escrow.activated_at == 0`, use `created_at` as fallback for the timeout check
  - Set terminal state before transfers: `{ let escrow = &mut ctx.accounts.escrow; escrow.state = MatchState::Cancelled; }` (OC-10)
  - Then do lamport refunds
