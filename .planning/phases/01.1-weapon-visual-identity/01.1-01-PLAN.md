Add two new utility methods to the Weapon class in client/src/classes/Weapon.js, placed after the existing updateTail method (around line 190) and before defaultUpdateScore.

1. **spawnParticle(x, y, color, size, lifetime, velocity)** -- Creates a temporary Phaser circle at (x,y) with the given hex color and radius `size`. Applies a tween that moves it by velocity.x/velocity.y over `lifetime` ms while fading alpha to 0, then destroys it on complete. Uses `weapon.scene.add.circle()` and `weapon.scene.tweens.add()` -- the exact same pattern already used in heatseeker's `releaseParticles` method and sniper rifle's `blast` method.

    Parameters:
    - x, y: world position (numbers)
    - color: hex color (e.g. 0xFFAA00)
    - size: circle radius in px (number, default 1)
    - lifetime: ms before fade-destroy (number, default 500)
    - velocity: {x, y} offset to drift toward (object, default {x: 0, y: 0})

    Implementation (approximately 15 lines):
    ```
    spawnParticle = (x, y, color, size = 1, lifetime = 500, velocity = {x: 0, y: 0}) => {
        var particle = this.scene.add.circle(x, y, size, color, 1)
        particle.setDepth(2)
        this.scene.tweens.add({
            targets: particle,
            x: particle.x + velocity.x,
            y: particle.y + velocity.y,
            alpha: 0,
            duration: lifetime,
            ease: 'Quad.easeOut',
            onComplete: () => { particle.destroy(true) }
        })
        return particle
    }
    ```

2. **spawnBurstEffect(x, y, count, color, spread, size, lifetime)** -- Creates `count` particles in a radial burst. For each particle, picks a random angle, random distance (0 to `spread`), and calls spawnParticle with that offset as velocity.

    Parameters:
    - x, y: center position
    - count: number of particles (default 8)
    - color: hex color
    - spread: max distance particles travel (default 20)
    - size: particle radius (default 1)
    - lifetime: ms (default 400)

    Implementation (approximately 12 lines):
    ```
    spawnBurstEffect = (x, y, count = 8, color = 0xffffff, spread = 20, size = 1, lifetime = 400) => {
        for (let i = 0; i < count; i++) {
            var angle = Math.random() * Math.PI * 2
            var dist = Math.random() * spread
            this.spawnParticle(
                x + (Math.random() - 0.5) * 4,
                y + (Math.random() - 0.5) * 4,
                color, size, lifetime,
                { x: Math.cos(angle) * dist, y: Math.sin(angle) * dist }
            )
        }
    }
    ```

These methods use ONLY existing Phaser APIs already used elsewhere in the codebase (scene.add.circle, scene.tweens.add). No new imports needed. No new dependencies.

IMPORTANT: Do NOT modify any other methods in Weapon.js. Do NOT touch defaultShoot, defaultUpdate, updateTail, defaultBounce, defaultDigTerrain, or any retract/check methods.
