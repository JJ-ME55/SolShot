## Decisions Made

- spawnParticle uses `particle.body.x / particle.body.y` is NOT used -- plain Phaser GameObject (scene.add.circle), not physics body. Uses tween `x`/`y` delta off initial position for drift -- correct since it's a visual-only object.
- Magic Wall rotation (`setRotation(rotation + 0.08)`) is applied BEFORE `defaultUpdate()` to avoid the physics update clobbering the rotation with velocity-derived angle. The slab is a static rectangle so default rotation doesn't suit it anyway.
- Dirt Ball dust particles emit from `this.projectile.body.x/y` (the physics body position, top-left corner) not `this.projectile.x/y` (sprite center) -- consistent with the rest of the codebase's use of body coordinates in update loops.
- Sniper Rifle muzzle flash uses the same turret tip formula as `defaultShoot` (`turret.x + (turret.height/2) * sin(rotation)`, `turret.y - (turret.height/2) * cos(rotation)`) -- guarantees flash appears exactly at barrel tip.
