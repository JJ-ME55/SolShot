## Accomplishments

- Big Shot is now a noticeably large 5px deep magenta sphere with a thick 8px smoky trailing plume -- visually heavy and dominant
- Skipper now emits a sandy dust/spark burst (using `spawnBurstEffect`) at each terrain bounce point; burst count decreases from 6 to 3 over 4 bounces
- Hailstorm main projectile is ice-blue (4px), sub-projectiles are angular ice shard polygons instead of green circles, and each sub-projectile hit produces a frost-white puff
- Crazy Ivan now jitters 1-2px per frame and oscillates trail color from purple (r=240, b=200) to red (r=120, b=120) via sin cycle on `_colorFrame`, with a ragged non-tapered trail
- Tommy Gun fires 12 alternating blue (`rgba(150,180,255)`) and gold-white (`rgba(255,240,200)`) tracer streaks with a warm muzzle flash burst per bullet fired

## Decisions Made

- Frost puff added in `hailstorm.onTerrainHit` in the sub-projectile (else) branch only. The main projectile branch calls `dissociate()` which is a splash event -- no redundant puff needed there.
- Skipper bounce burst added to `skipperBounce()` only (not also in `onTerrainHit`). The plan suggested both locations for coverage, but `skipperBounce` is only ever called from `onTerrainHit`, so adding to both would fire two bursts per bounce.
- Crazy Ivan jitter uses direct body position mutation (`this.projectile.body.x += ...`) consistent with how other weapons manipulate body position in their update loops.
- `_colorFrame` incremented only in the `dissipated === false` branch (pre-dissociation phase) -- no point cycling color on sub-particles, which have their own fixed purple trail.
