  After clearing the canvas, and before `weapon.defaultUpdate(this.projectile)`:
  ```
  // Spawn dirt eruption particles above the tunnel path
  if (this._eruptFrame === undefined) this._eruptFrame = 0
  this._eruptFrame++
  if (this._eruptFrame % 2 === 0) {
      // Find surface Y above current underground position
      var surfaceY = this.projectile.body.y
      for (var checkY = this.projectile.body.y; checkY >= 0; checkY--) {
          if (weapon.terrain.getPixel(Math.floor(this.projectile.body.x), Math.floor(checkY)).alpha === 0) {
              surfaceY = checkY
              break
          }
      }
      // Spawn dirt particles erupting upward from surface
      for (var d = 0; d < 3; d++) {
          weapon.spawnParticle(
              this.projectile.body.x + (Math.random() - 0.5) * 6,
              surfaceY,
              0x8B6914,   // dirt brown
              1 + Math.random(),
              500,
              { x: (Math.random() - 0.5) * 8, y: -(3 + Math.random() * 8) }
          )
      }
  }
  ```
  This creates dirt particles erupting upward from the terrain surface as the projectile tunnels below -- the "mole under a lawn" effect.
- `checkOutsideTerrain()`: When the projectile emerges (exits terrain), before `this.blast(weapon)`, add a debris burst: `weapon.spawnBurstEffect(this.projectile.body.x, this.projectile.body.y, 12, 0x8B6914, 20, 1.5, 400)` -- dramatic dirt debris spray on exit.
