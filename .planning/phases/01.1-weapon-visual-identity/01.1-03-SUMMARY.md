## Decisions Made

- Pile Driver burst ring uses `blastCount - 1` as the depth index because `blastCount` is incremented before the spawnBurstEffect call — this correctly maps to the just-executed blast depth
- Ground Hog surface scan iterates `checkY` from `body.y` upward (decrementing) stopping at the first alpha===0 pixel — finds terrain surface directly above the tunnel path
- Napalm particle loop runs every other frame (`_flameFrame % 2 === 0`) — 2 particles per fire event balances visual flame density without excessive particle count
- 3 Shot trail uses index===2 for center projectile (makeProjectile index param is 1/2/3, center is 2) — confirmed against existing create() logic
