## Decisions Made

- Tasks 1 and 2 committed as single commit (`59a32bd`) — both tasks modify the same file; without interactive TTY for `git add -p`, splitting into two commits is not feasible. Both sets of changes are documented in the commit message.
- Chain Reaction energy arc references `arr[i-2]` for previous blast position — `i` is incremented at end of `createBlast`, so inside the function body, `i` still refers to the current blast index. `arr[i-2]` is the blast before this one.
