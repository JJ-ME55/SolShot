The script should:
- Use `@metaplex-foundation/umi`, `@metaplex-foundation/umi-bundle-defaults`, `@metaplex-foundation/mpl-token-metadata`
- Load the dev keypair from `~/.config/solana/solshot-dev.json` (use `process.env.HOME` not hardcoded `~`)

  b. Burn mint authority: `spl-token authorize <NEW_MINT> mint --disable --url devnet`
  c. Update `server/.env` SHOT_TOKEN_MINT=<NEW_MINT>
  d. Update `client/.env` REACT_APP_SHOT_TOKEN_MINT=<NEW_MINT>
