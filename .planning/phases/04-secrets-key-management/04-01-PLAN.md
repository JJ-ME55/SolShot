<objective>
Create a centralized key-loading module (`server/services/keys.js`) and refactor `escrow.js` and `solana.js` to use it, eliminating duplicate keypair parsing and adding secret-key zeroization.

Purpose: Addresses KM-03 (key isolation via single shared module) and KM-04 (key material zeroization). Currently both `escrow.js` (lines 54-69) and `solana.js` (lines 81-100) independently parse the same `SOLANA_KEYPAIR_PATH/JSON` env var, creating two separate `Keypair` objects. The `solana.js` copy is dead code — never used for signing. This doubles heap exposure of the secret and violates the principle of a single point of key management.

Output: `keys.js` module, refactored `escrow.js` and `solana.js`
</objective>
