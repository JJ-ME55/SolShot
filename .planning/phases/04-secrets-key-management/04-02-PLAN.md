  <name>Task 1: Add key initialization, SIGHUP handler, and admin reload endpoint to index.js</name>
  <files>server/index.js</files>
  <action>
Modify `server/index.js` to add key management at startup and rotation support:

1. **Add imports** at the top (after existing imports):
   ```javascript
   import { initKeys } from './services/keys.js';
   import { initEscrow } from './services/escrow.js';
   ```
   Note: `initEscrow` is already imported indirectly via `initSolana()` in solana.js, but index.js needs a direct import to call it on SIGHUP reload.

2. **Add key initialization** after `dotenv.config()` and before Express setup:
   ```javascript
   // KM-03: Initialize key module at startup (before any escrow operations)
   const keysLoaded = initKeys();
   console.log(`[Server] Keys: ${keysLoaded ? 'LOADED' : 'NOT CONFIGURED (dev mode)'}`);
   ```
   This ensures keys are loaded BEFORE any socket connection triggers `getConnection()` → `initSolana()` → `initEscrow()`.

3. **Add SIGHUP handler** before the existing `process.on('uncaughtException')` block:
   ```javascript
   // KM-05: SIGHUP-triggered credential reload
   process.on('SIGHUP', () => {
       console.log('[Server] SIGHUP received — reloading credentials');
       const ok = initKeys();
       if (ok) {
           initEscrow();
           console.log('[Server] Credential reload complete');
       } else {
           console.error('[Server] Credential reload failed — escrow unchanged');
       }
   });
   ```

4. **Add protected admin reload endpoint** after the existing `/stats` endpoint and before the MongoDB connection block:
   ```javascript
   // KM-05: Protected key reload endpoint
   app.post('/api/admin/reload-keys', (req, res) => {
       const apiKey = req.headers['x-admin-key'];
       if (!process.env.ADMIN_API_KEY || apiKey !== process.env.ADMIN_API_KEY) {
           return res.status(401).json({ error: 'Unauthorized' });
       }
       if (process.platform === 'linux') {
           // On Linux/Render: self-signal SIGHUP (triggers the handler above)
           process.kill(process.pid, 'SIGHUP');
           return res.json({ ok: true, message: 'SIGHUP sent — credentials reloading' });
       }
       // On Windows/dev: reload directly (SIGHUP throws ENOSYS on Windows)
       const ok = initKeys();
       if (ok) initEscrow();
       res.json({ ok, message: ok ? 'Keys reloaded directly' : 'Key reload failed' });
   });
   ```

   The admin endpoint uses the existing `httpLimiter` middleware already applied globally via `app.use(httpLimiter)`. The `x-admin-key` header is checked against `ADMIN_API_KEY` env var. If `ADMIN_API_KEY` is not set, the endpoint always returns 401 (safe default).

   The Windows guard (`process.platform === 'linux'`) prevents `ENOSYS` errors during local development.

**Important:** Do NOT move or modify the existing `mainsocket(io)`, MongoDB connection, or process error handlers. The new code is additive — it inserts into the existing flow.
