# Phase 4.1 Plan 02: Permissionless Reclaim Safety Net Summary

## Objective

Add a `permissionless_reclaim` instruction to the Solana escrow program that allows anyone to
trigger refunds after 48 hours (2x normal timeout), providing a safety net for stuck escrows
that neither the authority nor the players have cancelled. Rebuild IDL and add server-side wrapper.

## What Was Built

### programs/solshot-escrow/src/lib.rs

Three additions made:

1. **`PERMISSIONLESS_RECLAIM_TIMEOUT` constant** — `TIMEOUT_SECONDS * 2 = 172800` seconds (48h)

2. **`permissionless_reclaim()` function** inside `#[program]` module:
   - Any wallet can call it (no authority/player constraint on caller)
   - Rejects if escrow is already Settled or Cancelled (`InvalidState`)
   - Uses `activated_at` if match was activated; falls back to `created_at`
   - Returns `TooEarlyToReclaim` if called before 48h has elapsed
   - Sets `MatchState::Cancelled` before lamport transfers (defense-in-depth)
   - Refunds deposited players, emits `MatchCancelled` event
   - Anchor's `close = caller` sends PDA rent to caller after instruction body

3. **`PermissionlessReclaim` accounts struct**:
   - `escrow`: mut + PDA seeds + `close = caller`
   - `caller`: `Signer<'info>` — any wallet, no constraint
   - `player_one` / `player_two`: constrained to `escrow.player_one/two`
   - `system_program`: required for `close` CPI
   - **No `config` account** — intentionally bypasses pause guard

4. **`TooEarlyToReclaim` error code** added to `EscrowError` enum

### server/idl/solshot_escrow.json

Rebuilt via `anchor build` after lib.rs changes. IDL now includes:
- `permissionless_reclaim` instruction (Anchor 0.32.x uses snake_case in IDL; JS SDK converts to camelCase at runtime)
- `TooEarlyToReclaim` error entry

### server/services/escrow.js

Two changes:
1. Added `SystemProgram` to `@solana/web3.js` import (required for `close = caller` CPI account)
2. Added `permissionlessReclaimEscrow(matchId, playerOneAddress, playerTwoAddress)` wrapper:
   - Uses `provider.wallet.publicKey` as caller (server receives the rent economic incentive)
   - Derives escrow PDA from `program.programId` (matches `getEscrowPDA()` pattern)
   - Returns `{ success, txSignature }` or `{ success: false, error }`

**2. [Observation] IDL instruction name is snake_case, not camelCase**

- **Found during:** Task 2 IDL verification
- **Observation:** Anchor 0.32.x generates `"permissionless_reclaim"` (snake_case) in IDL, not `"permissionlessReclaim"` (camelCase). The plan's `must_haves.artifacts.contains` value `"permissionlessReclaim"` doesn't match IDL reality.
- **Impact:** None — `@coral-xyz/anchor` JS SDK automatically converts snake_case instruction names to camelCase when building `.methods.permissionlessReclaim()` accessors. The IDL is correct as generated.
- **Action:** No change required. The JS wrapper uses `.permissionlessReclaim()` (camelCase) correctly.
