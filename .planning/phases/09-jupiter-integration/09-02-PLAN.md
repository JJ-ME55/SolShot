    3. **Update the wallets array** in `SolShotWalletProvider` — The Jupiter Mobile adapter should be FIRST in the array (wallet adapters render in order in the modal):

    If using `useWrappedReownAdapter` hook, the hook must be called inside the component. This means we need to restructure slightly. The hook returns an adapter instance. Add it to the wallets array:

    ```javascript
    export function SolShotWalletProvider({ children }) {
        // Jupiter Mobile adapter via Reown (must be called as hook)
        const jupiterAdapter = useWrappedReownAdapter({
            projectId: REOWN_PROJECT_ID,
        });

        const wallets = useMemo(() => {
            const list = [
                new PhantomWalletAdapter(),
                new SolflareWalletAdapter(),
            ];
            // Jupiter Mobile at position 0 (top of list) if adapter is available
            if (jupiterAdapter) {
                list.unshift(jupiterAdapter);
            }
            return list;
        }, [jupiterAdapter]);

        // ... rest unchanged
    }
    ```

    IMPORTANT: If `useWrappedReownAdapter` doesn't work as a hook (API mismatch), adapt the pattern. The key requirement is: Jupiter Mobile appears first, Phantom and Solflare still work.

    If REACT_APP_REOWN_PROJECT_ID is not set, skip Jupiter Mobile adapter (don't crash). Log a warning: `[SolShot] REACT_APP_REOWN_PROJECT_ID not set — Jupiter Mobile adapter disabled`.
