    The fallback adapter:
    - Extends `BaseWalletAdapter` from `@solana/wallet-adapter-base`
    - `name`: `'Jupiter'`
    - `url`: `'https://jup.ag/mobile'`
    - `icon`: Jupiter logo data URI or URL (use `'https://jup.ag/favicon.ico'` as a placeholder)
    - `readyState`: `WalletReadyState.Loadable` (importable from `@solana/wallet-adapter-base`)
    - `publicKey`: `null`
    - `connecting`: `false`
    - `connected`: `false`
    - `connect()`: Opens `https://jup.ag/mobile` in a new tab. Emits `'connect'` event. Does NOT actually connect a wallet — this is a promotional placeholder. Logs: `[JupiterMobileAdapter] Jupiter Mobile not available — opening download page`.
    - `disconnect()`: No-op, emits `'disconnect'` event.
    - `sendTransaction()`: Throws `WalletNotConnectedError`.

    ```javascript
    import { BaseWalletAdapter, WalletReadyState, WalletNotConnectedError } from '@solana/wallet-adapter-base';

    export class JupiterMobileAdapter extends BaseWalletAdapter {
        name = 'Jupiter';
        url = 'https://jup.ag/mobile';
        icon = 'https://jup.ag/favicon.ico';
        readyState = WalletReadyState.Loadable;
        publicKey = null;
        connecting = false;

        get connected() { return false; }

        async connect() {
            console.log('[JupiterMobileAdapter] Jupiter Mobile not available — opening download page');
            window.open('https://jup.ag/mobile', '_blank');
            this.emit('connect', this.publicKey);
        }

        async disconnect() {
            this.emit('disconnect');
        }

        async sendTransaction() {
            throw new WalletNotConnectedError();
        }
    }
    ```

    If using `useWrappedReownAdapter` hook, the hook must be called inside the component. This means we need to restructure slightly. The hook returns an adapter instance. Add it to the wallets array:

    ```javascript
    export function SolShotWalletProvider({ children }) {
        // Jupiter Mobile adapter via Reown (must be called as hook)
        const jupiterAdapter = useWrappedReownAdapter({
            projectId: REOWN_PROJECT_ID,
        });

        const wallets = useMemo(() => {
            const list = [
                new PhantomWalletAdapter(),
                new SolflareWalletAdapter(),
            ];
            // Jupiter Mobile at position 0 (top of list) if adapter is available
            if (jupiterAdapter) {
                list.unshift(jupiterAdapter);
            }
            return list;
        }, [jupiterAdapter]);

        // ... rest unchanged
    }
    ```
