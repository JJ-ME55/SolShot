In `client/src/screens/LobbyScreen.js`, make two changes:

**1. Replace formatWager with formatWagerWithPayout (UI-08):**
Find the existing `formatWager` function (around line 489):
```javascript
const formatWager = (amount) => {
  if (amount === 0) return 'FREE';
  return amount + ' SOL';
};
```

Replace it with:
```javascript
const formatWagerWithPayout = (amount) => {
  if (amount === 0) return 'FREE';
  const pot = (amount * 2).toFixed(2);
  const payout = (amount * 2 * 0.90).toFixed(3);
  return pot + ' SOL pot \u2014 winner takes ' + payout + ' SOL';
};
```

The formula: both players deposit `amount`, so pot = `amount * 2`. Winner gets 90% of pot (90/7/3 BPS split hardcoded in escrow program). Use `\u2014` for em dash.

Update ALL call sites that reference `formatWager` to use `formatWagerWithPayout` instead. There should be one call site in the room card JSX (around line 669): `{formatWager(room.wager || 0)}` becomes `{formatWagerWithPayout(room.wager || 0)}`.

Also check if formatWager is used in the wager selector section (left panel) — if so, update that call site too. If the left panel wager selector only shows the tier amount (not the room card display), it might use the raw amount display — in that case, leave it as-is and only update the room card display.

In `client/src/screens/ShopScreen.js`, enhance the prestige weapon section to show burn cost and tier requirement:

**1. Import PRESTIGE_TIERS:**
Add at the top of the file:
```javascript
import { PRESTIGE_TIERS } from '../data/tiers';
```

**2. Build prestige weapon metadata lookup:**
After imports, at module level (outside the component function), add:
```javascript
const PRESTIGE_WEAPON_META = {};
PRESTIGE_TIERS.forEach((tier) => {
  if (tier.weapons && tier.cost > 0) {
    tier.weapons.forEach((wId) => {
      PRESTIGE_WEAPON_META[wId] = {
        tierName: tier.name,
        burnCost: tier.cost,
        color: tier.color,
        reward: tier.reward,
      };
    });
  }
});
```

This maps: `{ 24: { tierName: 'Bronze', burnCost: 200, color: '#cd7f32', reward: 'Homing Missile' }, ... }`

**3. Enhance the prestige weapon detail panel:**
Find the existing prestige weapon section in the right panel (around the JSX that checks `selectedWeapon.tier.toLowerCase().includes('prestige')`):
```jsx
{selectedWeapon && selectedWeapon.tier && selectedWeapon.tier.toLowerCase().includes('prestige') && (
  <JupiterSwap
    mode="modal"
    buttonLabel="BUY SHOT TO UNLOCK"
    ...
  />
)}
```

Replace it with a richer display that includes burn cost and tier info:
```jsx
{selectedWeapon && (() => {
  const prestigeMeta = PRESTIGE_WEAPON_META[selectedWeapon.id];
  if (!prestigeMeta) return null;
  return (
    <div style={{ marginTop: 8, textAlign: 'center' }}>
      <div style={{
        fontFamily: "'Black Ops One', cursive",
        fontSize: 12,
        color: prestigeMeta.color,
        letterSpacing: 2,
        marginBottom: 4,
      }}>
        {prestigeMeta.tierName.toUpperCase() + ' PRESTIGE'}
      </div>
      <div style={{
        fontFamily: "'Share Tech Mono', monospace",
        fontSize: 11,
        color: 'var(--sp)',
        letterSpacing: 1,
        marginBottom: 6,
      }}>
        {'REQUIRES ' + prestigeMeta.burnCost.toLocaleString() + ' SHOT BURN'}
      </div>
      <JupiterSwap
        mode="modal"
        buttonLabel={'BUY SHOT TO UNLOCK ' + prestigeMeta.tierName.toUpperCase()}
        buttonStyle={{ fontSize: 8, padding: '5px 10px' }}
      />
    </div>
  );
})()}
```

This replaces the old simple `selectedWeapon.tier.toLowerCase().includes('prestige')` check with a PRESTIGE_WEAPON_META lookup, which is more precise (uses actual weapon IDs from tiers.js) and provides tier-specific metadata.

**IMPORTANT:** The old check `selectedWeapon.tier.toLowerCase().includes('prestige')` may still work as a fallback for weapons that have `tier: 'PRESTIGE'` in weapons.js. But the new check via PRESTIGE_WEAPON_META is authoritative because it uses the actual tier definitions. If a weapon has tier 'PRESTIGE' but is NOT in PRESTIGE_WEAPON_META (which shouldn't happen), the IIFE returns null and the old JupiterSwap button won't render. This is acceptable — PRESTIGE_WEAPON_META covers all 5 prestige weapons (IDs 21, 22, 24, 26, 29).

Use string concatenation for all text to avoid ESLint/Collider.js issues.
