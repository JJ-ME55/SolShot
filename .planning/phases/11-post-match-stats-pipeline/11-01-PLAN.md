**Enrich matchEnd payload** — In the match end section (near line ~2270 where `matchEndPayload` is constructed), add two new fields:

1. `prestigeInfo`: Call `getPrestigeInfo(wallet)` for both host and player, include in payload as `prestigeInfo: { [hostId]: hostPrestige, [playerId]: playerPrestige }` so each client can read their own prestige data from `matchEndPayload.prestigeInfo[myId]`.

2. `earnedMilestones`: For each player's `shotResults`, extract the milestones earned in this match. Currently `recordMatchPlayed` returns `{ earned, milestone, newBalance, matchesPlayed }` where `milestone` is only the LAST milestone label. To get ALL milestones earned, modify the approach:
   - BEFORE the `recordMatchPlayed` calls (around line ~2234), capture the player's current milestones:
     ```js
     const hostMilestonesBefore = hostWallet ? new Set((getPlayerShotState(hostWallet)?.milestonesEarned || [])) : new Set();
     const playerMilestonesBefore = playerWallet ? new Set((getPlayerShotState(playerWallet)?.milestonesEarned || [])) : new Set();
     ```
   - AFTER the `recordMatchPlayed` calls, compute newly earned milestones:
     ```js
     const getNewMilestones = (wallet, beforeSet) => {
         if (!wallet) return [];
         const state = getPlayerShotState(wallet);
         if (!state) return [];
         return (state.milestonesEarned || [])
             .filter(id => !beforeSet.has(id))
             .map(id => {
                 const ms = SHOT_MILESTONES.find(m => m.id === id);
                 return ms ? { id: ms.id, label: ms.label, reward: ms.reward } : null;
             })
             .filter(Boolean);
     };
     ```
   - Add to matchEndPayload: `earnedMilestones: { [hostId]: getNewMilestones(hostWallet, hostMilestonesBefore), [playerId]: getNewMilestones(playerWallet, playerMilestonesBefore) }`

   NOTE: `getPlayerShotState` is NOT currently exported from shot-token.js. You need to either:
   (a) Export it: add `export` to the `function getPlayerShotState` declaration in shot-token.js, OR
   (b) Create a new exported helper `getEarnedMilestoneIds(walletAddress)` that returns the array.
   Option (a) is simpler. Also import `SHOT_MILESTONES` in main.js (it's already exported from shot-token.js but may not be imported in main.js — check the import line at the top).
