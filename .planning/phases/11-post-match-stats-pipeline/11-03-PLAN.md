**ShareCard.js** — Create a new component that renders an offscreen single-match result card. This is NOT the CombatCard (which shows lifetime stats). This is a simpler, lighter card for sharing a single match result.

Props: `{ isWin, solAmount, shotEarned, onExported }` (onExported callback after clipboard copy succeeds)

Structure:
- Outer wrapper: position 'absolute', left -9999, top -9999 (offscreen for html2canvas capture)
- Card: width 320, fixed height ~180px
- Background: linear-gradient dark military theme (matching app style)
- Top stripe: 2px gradient (green for win, red for loss)
- Content:
  - "VICTORY" or "DEFEAT" header (Bebas Neue, 28px, green or red)
  - SOL earned/lost line (if wager > 0): "+0.180 SOL" green or "-0.100 SOL" red
  - SHOT earned line (if > 0): "+25 SHOT"
  - Footer: "SOLSHOT.GG" in Black Ops One, "Artillery Combat on Solana" tagline
- Bottom stripe: 2px gradient

Expose an `exportToClipboard` method via `React.forwardRef` + `useImperativeHandle`:
```js
const ShareCard = React.forwardRef(({ isWin, solAmount, shotEarned, onExported }, ref) => {
    const cardRef = useRef(null);

    useImperativeHandle(ref, () => ({
        exportToClipboard: async () => {
            if (!cardRef.current) return false;
            try {
                const canvas = await html2canvas(cardRef.current, {
                    backgroundColor: '#0a0c08',
                    scale: 2,
                    logging: false,
                    useCORS: true,
                });
                const blob = await new Promise(r => canvas.toBlob(r, 'image/png'));
                if (navigator.clipboard && window.ClipboardItem) {
                    await navigator.clipboard.write([new window.ClipboardItem({ 'image/png': blob })]);
                    if (onExported) onExported(true);
                    return true;
                }
            } catch (e) {
                console.error('[ShareCard] Export failed:', e);
            }
            if (onExported) onExported(false);
            return false;
        }
    }));
    // ... render offscreen card
});
```
