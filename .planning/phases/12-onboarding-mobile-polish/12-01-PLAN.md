  <name>Task 1: Create haptic feedback utility and expose globally</name>
  <files>client/src/utils/haptic.js</files>
  <action>
Create `client/src/utils/haptic.js` — a ~20-line utility module that provides haptic feedback with three intensity levels.

Implementation:
1. Define three vibration patterns:
   - `light()` — 10ms vibration (UI taps, menu selections)
   - `medium()` — 25ms vibration (shot fired, turn events)
   - `heavy()` — [50, 30, 50]ms pattern (damage received, win/lose)

2. Each method must:
   - Check `typeof navigator !== 'undefined' && navigator.vibrate` before calling
   - Silently no-op on unsupported platforms (desktop, iOS Safari without workaround)
   - Never throw errors

3. iOS Taptic Engine workaround (Safari 17.4+):
   - On module init, detect iOS: `/(iPhone|iPad)/.test(navigator.userAgent)`
   - If iOS, create a hidden `<input type="checkbox" style="display:none">` element and set its `switch` attribute
   - For iOS haptic: programmatically toggle the checkbox `.click()` which triggers Taptic Engine
   - This is a best-effort enhancement — if it fails, silently no-op

4. Export a `haptic` object with `{ light, medium, heavy }` methods
5. Assign to `window.haptic` on module load so Phaser scenes can call it without imports
6. Also export normally for React component imports

Do NOT use any npm packages for haptic/vibration. This is pure browser API.
  </action>

    - Contains window.haptic assignment

    - No external dependencies imported
