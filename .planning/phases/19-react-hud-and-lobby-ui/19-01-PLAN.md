**2. Create `client/src/screens/battle/PlayerHPBar.js` -- new component**

A self-contained HP bar component that replaces ScoreBoard for the N-player strip. It does NOT modify or import ScoreBoard -- it is a standalone component sharing similar visual design.

Key props: `player` (object with hp, name, color, alive, placement), `isActive` (boolean -- is this the current turn player), `isMe` (boolean -- is this the local player).

Implementation details:
- `const MAX_HP = 250`
- Compute `hp` percentage: `Math.max(0, Math.min(100, Math.round((rawHp / MAX_HP) * 100)))` where `rawHp = player?.hp ?? MAX_HP`
- Detect eliminated: `const isEliminated = player?.alive === false` (explicit check for `false`, not just falsy)
- Damage trail effect: Use `useRef` for `prevHpRef` and `useState` for `damagePct`. When `rawHp < prevHpRef.current`, show old percentage briefly then animate down (same pattern as ScoreBoard's useEffect).
- Damage popup: When damage taken, show `-{dmg}` text with fade-up animation.

Layout (vertical stack, `flex: 1, minWidth: 0`):
```
  [Arrow] [ColorDot] [Name or "YOU"]    <-- name row
  [HP Bar or "OUT 3rd"]                  <-- bar row
```

Name row:
- If `isActive`, render `\u25B6` (black right-pointing triangle) in `var(--am)` color, fontSize 9.
- Color dot: 7x7px, borderRadius 2, background = `player?.color || '#FFF'`.
- Name text: `isMe ? 'YOU' : (player?.name || 'UNKNOWN')`. Font: `'Black Ops One', cursive`, fontSize 11. Truncate with `overflow: hidden, textOverflow: 'ellipsis', whiteSpace: 'nowrap'`.

HP bar row (height 12px):
- If eliminated: grey bar `rgba(100,100,100,0.3)` with centered text `OUT` + ordinal placement (e.g., `OUT 4th`). Ordinal helper: `n===1?'1st':n===2?'2nd':n===3?'3rd':n+'th'`. Font: fontSize 9, color `var(--kh)`, letterSpacing 1.
- If alive: outer container `rgba(184,168,138,0.12)` with `1px solid rgba(184,168,138,0.2)`, borderRadius 2, overflow hidden. Inside: trailing damage bar (red ghost, `rgba(255,80,60,0.4)`, transition `width 1.2s ease-out 0.3s`) and current HP fill (green/orange/red gradient based on hp %, transition `width 0.4s ease-out`). HP number overlay centered: `{rawHp} / {MAX_HP}`, fontSize 10, color `#fff`, textShadow.
- Damage popup positioned absolute, animates up and fades out over 1s. Use `@keyframes dmgFlash` same as ScoreBoard.

Wrap in `React.memo` for performance.

**1. BattleScreen.js -- Leave Match wiring with race guard**

Add a `leftMatchRef` to prevent double-navigate when Leave Match and matchEnd fire simultaneously:
```javascript
const leftMatchRef = useRef(false);
```

Create a `handleLeaveMatch` callback:
```javascript
const handleLeaveMatch = useCallback(() => {
  leftMatchRef.current = true;
  if (window.socket) {
    window.socket.emit('leaveRoom');
  }
  destroyBattle();
  navigate('lobby');
}, [navigate]);
```

Guard the existing `matchEnd` socket handler with the ref:
```javascript
useSocket('matchEnd', (data) => {
  if (leftMatchRef.current) return;  // Already navigating via Leave Match
  const myId = window.socket?.id;
  const isWinner = data.winner === myId;
  haptic.heavy();
  navigate(isWinner ? 'win' : 'lose', {
    ...screenData,
    ...data,
  });
});
```

Pass `onLeaveMatch` to BattleHUD:
```jsx
<BattleHUD
  bridge={bridge}
  gameState={gameState}
  wager={wager}
  onLeaveMatch={handleLeaveMatch}
/>
```
