**3. Emit roomUpdate on disconnect/leave from waiting room**

In the `cleanupRoom` function, there is a branch where the room is not in an active match (no match state or match is in LOBBY status). When a player is removed from a non-active room and the room still has players remaining, emit roomUpdate to them.

Find the section at the END of `cleanupRoom` that does:
```javascript
            client.leave(roomId)
            await removeRoom(roomId)
            io.sockets.in(roomId).emit('opponentLeft', {})
            broadcastRooms(io)
            io.socketsLeave(roomId)
```

This is the catch-all cleanup path. The issue: `removeRoom` deletes the room entirely, so remaining players in a partially-filled waiting room lose their room. For the case where the room is not active (no match started) and has remaining players, we should NOT destroy the room -- we should just remove the leaving player and emit roomUpdate.

Modify this section: BEFORE `client.leave(roomId)`, check if the room exists and is NOT active (no match started). If so, remove only the disconnecting player from `room.players`, emit `roomUpdate` to remaining players, and skip the `removeRoom` call:

```javascript
            const cleanupRoom2 = findRoom(roomId)
            if (cleanupRoom2 && !cleanupRoom2.active && cleanupRoom2.players && cleanupRoom2.players.length > 1) {
                // Room is in waiting state with other players -- just remove this player
                cleanupRoom2.players = cleanupRoom2.players.filter(p => p.socketId !== client.id)
                client.leave(roomId)
                client.roomId = null
                client.isHost = false
                // Promote next player to host if needed
                if (cleanupRoom2.players.length > 0 && !cleanupRoom2.players.some(p => p.isHost)) {
                    cleanupRoom2.players[0].isHost = true
                }
                io.sockets.in(roomId).emit('roomUpdate', {
                    players: cleanupRoom2.players.map(p => ({
                        socketId: p.socketId,
                        name: p.name,
                        color: p.color,
                        isReady: p.isReady || false,
                        isHost: p.isHost || false,
                    })),
                    maxPlayers: cleanupRoom2.maxPlayers,
                    currentPlayers: cleanupRoom2.players.length,
                })
                broadcastRooms(io)
                return
            }
            client.leave(roomId)
            await removeRoom(roomId)
            io.sockets.in(roomId).emit('opponentLeft', {})
            broadcastRooms(io)
            io.socketsLeave(roomId)
            client.roomId = null
            client.isHost = false
```

The key logic: if the room is not active (waiting for players) and has >1 player, removing one player just updates the waiting room. If only 1 player remains or if the match was active, fall through to the existing destroy-room path.
