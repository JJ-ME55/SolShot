**CRITICAL N-PLAYER API CHANGES (apply everywhere):**

1. **`createMatch` signature changed** — the third arg is now a `PublicKey[]` array, not two separate pubkeys:
   ```typescript
   // OLD (WRONG):
   .createMatch(matchId, new anchor.BN(wager), playerOne.publicKey, playerTwo.publicKey)
   // NEW (CORRECT):
   .createMatch(matchId, new anchor.BN(wager), [playerOne.publicKey, playerTwo.publicKey])
   ```

2. **Escrow field reads changed** — no more playerOne/playerTwo/playerOneDeposited/playerTwoDeposited:
   ```typescript
   // OLD (WRONG):
   escrow.playerOne, escrow.playerTwo, escrow.playerOneDeposited, escrow.playerTwoDeposited
   // NEW (CORRECT):
   escrow.players     // Pubkey[4] fixed array (zero-padded)
   escrow.maxPlayers  // u8 — number of active players (2-4)
   escrow.depositsMask // u8 — bitmap where bit N = player N deposited
   ```
   To check if player at index `i` deposited: `(escrow.depositsMask & (1 << i)) !== 0`
   To check all players deposited (full mask for N players): `escrow.depositsMask === (1 << escrow.maxPlayers) - 1`

3. **`cancelMatch` accounts changed** — no more playerOne/playerTwo in accounts. Players arrive via `remainingAccounts`:
   ```typescript
   // OLD (WRONG):
   .cancelMatch()
   .accounts({
     escrow: escrowPDA,
     caller: authority.publicKey,
     playerOne: playerOne.publicKey,
     playerTwo: playerTwo.publicKey,
     config: configPDA,
     systemProgram: anchor.web3.SystemProgram.programId,
   })
   .rpc();

   // NEW (CORRECT):
   .cancelMatch()
   .accounts({
     escrow: escrowPDA,
     caller: authority.publicKey,
     config: configPDA,
     systemProgram: anchor.web3.SystemProgram.programId,
   })
   .remainingAccounts(
     depositedPlayerKeypairs.map(kp => ({
       pubkey: kp.publicKey,
       isSigner: false,
       isWritable: true,
     }))
   )
   .rpc();
   ```
   IMPORTANT: Only pass accounts for players whose bit is SET in deposits_mask. Pass them in player-index order. If no players deposited, pass empty array.

```typescript
async function createAndActivateMatch(
  program: Program<SolshotEscrow>,
  provider: anchor.AnchorProvider,
  authority: anchor.Wallet,
  matchId: string,
  players: Keypair[],
  configPDA: PublicKey,
  wager: number = WAGER
): Promise<PublicKey> {
  const [escrowPDA] = PublicKey.findProgramAddressSync(
    [Buffer.from("match"), Buffer.from(matchId)],
    program.programId
  );

  await program.methods
    .createMatch(matchId, new anchor.BN(wager), players.map(p => p.publicKey))
    .accounts({
      escrow: escrowPDA,
      authority: authority.publicKey,
      config: configPDA,
      systemProgram: anchor.web3.SystemProgram.programId,
    })
    .rpc();

  for (const player of players) {
    await program.methods
      .depositWager()
      .accounts({
        escrow: escrowPDA,
        player: player.publicKey,
        config: configPDA,
        systemProgram: anchor.web3.SystemProgram.programId,
      })
      .signers([player])
      .rpc();
  }

  return escrowPDA;
}
```
