<task id="1" title="Update solana.js settleMatch and refundWager for N-player">
Three changes to `server/services/solana.js`:

**A) Update `settleMatch` to accept `playerCount` param:**

**Old signature:** `settleMatch(winnerAddress, loserAddress, wagerSOL, matchId)`
**New signature:** `settleMatch(winnerAddress, loserAddress, wagerSOL, matchId, playerCount = 2)`

Changes:
1. Add `playerCount = 2` as fifth parameter (default 2 for backward compat)
2. Change line `const totalPot = wagerSOL * 2` to `const totalPot = wagerSOL * playerCount`
3. Update JSDoc to document the new param
4. Keep everything else the same — `settleMatchEscrow(matchId, winnerAddress)` call is unchanged

**B) Update `refundWager` to accept player addresses array:**

**Old signature:** `refundWager(playerAddress, wagerSOL, matchId, playerOneAddress, playerTwoAddress)`
**New signature:** `refundWager(playerAddress, wagerSOL, matchId, playerAddresses)`

Where `playerAddresses` is a `string[]` of deposited player addresses (or undefined for non-escrow).

Changes:
1. Replace `playerOneAddress, playerTwoAddress` params with `playerAddresses` (array or undefined)
2. Change the escrow-enabled guard: `if (isEscrowEnabled() && matchId && playerAddresses && playerAddresses.length > 0)`
3. Change the call: `cancelMatchEscrow(matchId, playerAddresses)` (already an array, matching 21-01 signature)
4. Update JSDoc

**C) Add re-export for `startWithDepositorsEscrow`:**

Add to the re-export block at the bottom of solana.js:
```javascript

    isEscrowEnabled,
    createMatchEscrow,
    buildDepositTransaction,
    getEscrowState,
    getEscrowPDA,
    startWithDepositorsEscrow,
} from './escrow.js';
```

- Default `playerCount = 2` means existing callers that don't pass a count still work
