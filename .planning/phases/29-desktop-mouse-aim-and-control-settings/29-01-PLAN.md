  <name>Task 1: Create useControlScheme hook</name>
  <files>client/src/hooks/useControlScheme.js</files>
  <action>
Create a new React hook `useControlScheme(isMobile)` that:

1. Reads `localStorage.getItem('solshot_control_scheme')` on init
2. If no stored value, defaults to `'mouse'` on desktop (`!isMobile`) and `'classic'` on mobile
3. Returns `[scheme, updateScheme]` tuple
4. `updateScheme(v)` writes to localStorage AND sets `window.controlScheme = v`
5. `useEffect` syncs `window.controlScheme = scheme` on mount and when scheme changes
6. Export as default function

Use the exact pattern from 29-RESEARCH.md Pattern 3. The localStorage key must be `'solshot_control_scheme'`.
