Add mouse-aim input handling to MainScene. This is a single-file change to `client/src/scenes/main/index.js`. Follow the research patterns exactly.

**1. Add guard function `_isMouseAimActive()`:**
Place as a method on the scene (or arrow function stored on `this`). Checks ALL of:
- `window.controlScheme === 'mouse'`
- `!window.isMobile` (skip if window.isMobile is not reliably set — in that case, rely solely on controlScheme since the hook defaults to 'classic' on mobile)
- `this.myPlayerIndex >= 0`
- `this.myPlayerIndex === this.currentPlayerIndex` (it's my turn)
- `!this._firePending` (not mid-fire)

If `window.isMobile` is not set elsewhere in the codebase, omit that check — `controlScheme` already discriminates since the hook defaults to `'classic'` on mobile.

**2. Register handlers in `handleType3()` (or the scene init method that sets up socket handlers):**

Create `this._mouseAimHandlers` object with `move` and `down` functions:

`move` handler (pointermove):
- Guard: `if (!this._isMouseAimActive()) return;`
- Get `myTank = this.tanks[this.myPlayerIndex]`
- Guard: `if (!myTank?.turret || !myTank.active) return;`
- Calculate angle using `Phaser.Math.Angle.Between(myTank.turret.x, myTank.turret.y, pointer.worldX, pointer.worldY)`
- Set `myTank.turret.relativeRotation = absoluteAngle - myTank.rotation`
- Set `myTank.turret.setRotation(absoluteAngle)`
- Set `myTank.turret.needEmitAngleChange = true`
- Calculate power: `dist = Phaser.Math.Distance.Between(myTank.turret.x, myTank.turret.y, pointer.worldX, pointer.worldY)`
- `const MAX_DIST = this.renderer ? this.renderer.width * 0.30 : 250;`
- `const power = Math.round(Phaser.Math.Clamp((dist / MAX_DIST) * 100, 5, 100));`
- Call `myTank.setPower(power)` — this method should already exist in Tank.js (verify by reading the file; if it stores power and triggers bridge update, use it; if not, set `myTank.power = power` and trigger `_pushStateToBridge` however the existing code does it)

`down` handler (pointerdown):
- `if (pointer.button !== 0) return;` — left click only
- `if (!this._isMouseAimActive()) return;`
- Call `this.handleFireFromReact()` — this is the existing fire handler used by the React FIRE button

Register both:
```javascript
this.input.on('pointermove', this._mouseAimHandlers.move);
this.input.on('pointerdown', this._mouseAimHandlers.down);
```

**3. Clean up in `shutdown()`:**
Find the existing `shutdown()` method. Add cleanup BEFORE or alongside the existing socket handler cleanup:
```javascript
if (this._mouseAimHandlers) {
  this.input.off('pointermove', this._mouseAimHandlers.move);
  this.input.off('pointerdown', this._mouseAimHandlers.down);
  this._mouseAimHandlers = null;
}
```
