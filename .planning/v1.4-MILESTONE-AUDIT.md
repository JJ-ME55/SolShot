## Critical Gaps

### GAP-1: settleMatch playerCount defaults to 2 at all call sites

**Severity:** HIGH — affects settlement display and monitoring for all N>2 matches
**Location:** `server/socket-io/main.js` lines 536, 840, 2672

`settleMatch(winnerAddress, loserAddress, wagerSOL, matchId, playerCount = 2)` is called without the 5th argument at all 3 call sites. The on-chain Anchor program correctly settles `wager * deposits_mask.count_ones()` — **no financial loss** — but the JS-side `settlement` object (totalPot, winnerPayout, fees) uses `wager * 2` regardless of actual player count.

**Impact:**
- `settlementInfo.totalPot` emitted in `matchEnd` event → client shows wrong pot for N>2
- `settlementInfo.winnerPayout` → wrong winner display
- `trackSettlement()` monitoring metrics → wrong values
- Console logs → incorrect amounts

**Fix:** Pass `room.players.length` as 5th arg at all 3 call sites.

### GAP-2: Disconnect even-score refund only cancels for 2 players

**Severity:** HIGH — SOL locked in escrow PDA for players[2]/[3] until permissionless_reclaim timeout
**Location:** `server/socket-io/main.js` lines 820–824

```javascript
const p1w = ws.wallets[room.players?.[0]?.socketId]
const p2w = ws.wallets[room.players?.[1]?.socketId]
await cancelMatchEscrow(roomId, [p1w, p2w].filter(Boolean))
```

In a 3- or 4-player match where scores are even on disconnect, only players[0] and players[1] are refunded. Players[2] and [3] must wait for `permissionless_reclaim` timeout (20 minutes).

**Fix:** `room.players.map(p => ws.wallets[p.socketId]).filter(Boolean)`

### GAP-3: Lobby-state disconnect refund slices only first 2 wallets

**Severity:** HIGH — same locked-SOL issue as GAP-2
**Location:** `server/socket-io/main.js` lines 876–880

```javascript
const allWallets = Object.values(ws.wallets).filter(Boolean)
const p1w = allWallets[0] || null
const p2w = allWallets[1] || null
await refundWager(wallet, ws.amount, roomId, [p1w, p2w].filter(Boolean))
```

For N>2 player rooms, only the first 2 wallet entries are passed to `refundWager`.

**Fix:** `await refundWager(wallet, ws.amount, roomId, allWallets)`
