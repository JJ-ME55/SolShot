## REDDIT / FORUM POST (r/solana, r/CryptoGaming)

**Title:** SolShot — Multiplayer artillery game on Solana with real SOL wagering

**Body:**

Built a browser-based artillery game (think Pocket Tanks / Scorched Earth) where you can wager SOL against opponents.

Core mechanics:
- 1v1 PvP on destructible terrain
- 13 weapons with unique physics (not reskins)
- Server-authoritative — all calculations server-side, client sends inputs only
- Wagers held in on-chain escrow, settled automatically
- Winner takes 90%, 7% treasury, 3% ops

Also has a token system (SHOT) earned through gameplay milestones — not purchased. You burn SHOT permanently for prestige tiers that unlock exclusive weapons. Deflationary by design.

Stack: Phaser.js client, Express/Socket.IO server, MongoDB, Solana (Anchor).

Live on devnet. Would appreciate feedback from anyone who tries it.
